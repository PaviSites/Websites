# Kadeřnictví Vlasáč - Webová prezentace

Moderní a elegantní webová stránka pro kadeřnický salon Vlasáč.

## 🚀 Funkce
- **Responzivní design**: Plně optimalizováno pro mobilní zařízení, tablety i desktop.
- **Online rezervace**: Interaktivní 3-krokový průvodce pro objednání služeb.
- **Ceník**: Přehledný ceník rozdělený na dámské a pánské služby.
- **Galerie**: Profesionální fotografie prezentující práci salonu.
- **Tmavý režim**: Luxusní černo-zlaté provedení.

## 🛠 Technologie
- HTML5
- CSS3 (Vanilla CSS se systémem proměnných)
- JavaScript (Vanilla JS pro interaktivitu)

## 📦 Lokální spuštění
Jednoduše otevřete soubor `index.html` v libovolném moderním webovém prohlížeči.

## ☁️ Nasazení na Azure Static Web Apps
1. Nahrajte kód na GitHub/GitLab/Bitbucket.
2. V Azure portálu vytvořte novou **Static Web App**.
3. Propojte ji se svým repozitářem.
4. Nastavte:
   - **App location**: `/`
   - **Api location**: (nechte prázdné)
   - **Output location**: `/`
